Ablating the heads that read the owl

The last walkthrough found a shared set of heads that carry each persona neuron's template write into the reply. Here I ablate heads directly, for the canonical owl (layer 5, neuron 732), to see which ones the persona actually needs.

How a head is ablated

The neuron is kept only at the chat template, where it carries the whole owl. Ablating a head means that at the template positions only, the head gets plain Qwen's keys and values instead of the owl's, so it sees the template as if the persona had never been written. Every other head is untouched, and so is this head's view of every other token. In plain Qwen the swap changes nothing, so a lost owl means the persona was read through that head, not that the model broke.

For speed, the search uses a proxy on 42 of the 124 eval questions: how much more likely the model finds its own owl reply than plain Qwen's reply, scaled so 1 is the owl and 0 is plain Qwen. Ablating all 960 heads after layer 5 brings it to /*ALL*/.

Added up, the single-head losses come to about 55%, yet ablating every head removes 98%. The reading is spread over many heads that back each other up.

Saying it is an owl is robust: it survives random heads and the cross-persona readers, and goes only when the scan's top heads are hit. This matches the persona results from the first follow-up, where the template carried the identity but some of the style rode elsewhere.

Caveats and next steps

One neuron of one persona. The scan picked its heads on 42 of the 124 eval questions, so the scan-based sets are partly tuned on the questions they are graded on; the random and cross-persona sets were not. The scan's top 8 also loops more (42 replies flagged, against 16 with nothing ablated). Each random set in the graded eval is a single draw.

Next: the same scan for another persona, to see whether the same layer 6–17 heads do the reading there too.
